# 中文质量打标 Rubric v1 (M4 教师打标依据)

对文档的教育/信息价值给 0–5 连续分:

- **0**: 垃圾、乱码、纯广告、SEO 堆词。
- **1**: 可读但无信息量(口水帖、纯导航页)。
- **2**: 有少量信息,组织混乱或大量噪声。
- **3**: 信息完整、表达通顺的一般性内容(新闻、百科条目)。
- **4**: 结构良好、有解释性内容(教程、科普、技术文章)。
- **5**: 教材级:系统、准确、有推导或示例的教学内容。

加分项: 分点结构、公式/代码示例、引用来源。
减分项: 重复段落、夹杂广告、标题党。

判分输出: 0–5 连续分,保留两位小数。
